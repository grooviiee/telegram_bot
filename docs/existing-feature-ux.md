# 기존 분석 기능 UX

웹에서 기업 검색 → 재무·사업·밸류에이션 확인 → AI 상담으로 이어지는 흐름을 개선했습니다.

- 조회에 성공한 기업명을 화면 상단에 표시하고 다음 분석 화면에 전달합니다. AI 리포트와 주가 이벤트는 기업명만 채우고, 사용자가 조회 버튼을 눌렀을 때 실행합니다.
- 검색창은 기업명 라벨, 빈 검색 방지, 예시 기업 버튼, 한글 조합 중 Enter 중복 실행 방지를 공통으로 제공합니다. 즐겨찾기의 추가·해제 상태도 키보드와 화면 읽기 도구로 확인할 수 있습니다.
- 모바일에서 로고·즐겨찾기와 분석 메뉴를 두 줄로 나눴습니다. 분석 메뉴 안에서 가로 스크롤하며 모든 항목에 접근할 수 있습니다.
- 로딩 화면은 경과 시간을 표시합니다. 서버가 진행률을 제공하지 않으므로 시간에 따라 가상의 완료율이나 처리 단계를 표시하지 않습니다.
- 연도·분기 조회 실패 시 오류 안내와 재시도 버튼을 제공합니다. 기업을 바꾸거나 화면을 떠나면 공통 조회 훅의 이전 요청을 취소하고, 늦게 도착한 결과가 새 조회를 덮어쓰지 않도록 합니다.
- 종합 분석은 재무·배당을 독립적으로 표시합니다. 한쪽 조회가 실패해도 성공한 결과를 볼 수 있습니다. 재무제표의 조회 기간과 연결·개별 구분도 표시합니다.
- 기존 `analysis` 키로 저장된 종합 분석 즐겨찾기를 계속 열 수 있고, 모든 분석 항목을 한글 이름으로 표시합니다. 손상된 저장값은 건너뜁니다. 저장 위치는 기존과 동일하게 현재 브라우저의 localStorage입니다.

`/analysis`, `/valuation`, `/chat` 등 직접 주소로 접속하면 해당 분석 화면이 열립니다. 분석 UI는 `components/screens/`에 두고 Next.js 라우트는 진입 화면만 지정합니다.

기업 선택은 현재 웹 세션에서 이어집니다. 화면을 전환하면 해당 화면은 다시 조회하며 서버 캐시를 이용합니다.

## 검증

```bash
cd frontend/next
npm ci
npx playwright install chromium
npm run lint
npx tsc --noEmit
npm run build
# 다른 터미널에서 웹을 실행한 다음:
npm run dev
# 새 터미널에서:
npm run test:ux
```

`test:ux`는 Playwright로 데스크톱과 390px 모바일 브라우저를 실행합니다. 공시·AI API는 고정 응답으로 대체하여 API 키 없이 기업 이어보기, 예전 즐겨찾기 열기, 명시적인 AI 리포트 생성, 실패 후 재시도, 분기 조회 복구, 없는 기업 조회 후 정상 검색, AI 상담, 모바일 메뉴와 가로 넘침, 늦은 이전 요청의 영향, 잘못된 JSON 응답 후 재시도, 긴 상담의 입력창 위치, 직접 주소 진입을 확인합니다. 실제 DART·AI 응답 품질을 검증하는 테스트는 아닙니다.

기본 웹 주소는 `http://127.0.0.1:3000`입니다. 다른 주소는 `UX_BASE_URL`로 지정합니다. 웹을 빌드·실행할 때 `NEXT_PUBLIC_API_BASE_URL`을 지정했다면 테스트 실행에도 같은 값을 지정합니다. 실행 결과 화면은 Git에서 제외된 `frontend/next/ux-artifacts/`에 저장됩니다.
