# 분석 신뢰성과 AI 호출 정책

## 사용자 동작

- 재무·배당·밸류에이션·점수 조회, 공시 접수 알림, 기본 내부자 현황에는 AI를 사용하지 않습니다.
- 버핏 화면에서는 정량 데이터를 먼저 조회하고 **AI 해석 생성** 버튼을 눌러야 리포트를 생성합니다.
- 일반 리포트와 주요 사건 화면도 즐겨찾기에서 진입했다는 이유만으로 AI를 호출하지 않습니다.
- `/chat/{company}`는 단일 지표 질문(예: `2025년 매출 알려줘`, `ROE`, `현재가`)에 코드로 답합니다. 원인·위험·전망 등 자유형 해석은 AI로 처리합니다. 지원하는 단순 문장만 전체 일치로 구분하며 AI 분류기를 호출하지 않습니다.
- `/insider/{company}`는 기본적으로 사실 집계만 반환합니다. 추가 해석은 `?ai_analysis=true`로 명시적으로 요청합니다. 소유주식 증가·감소를 실제 매수·매도로 단정하지 않습니다.
- AI 키가 없어도 정량 API 서버는 동작합니다. AI 요청만 503으로 응답합니다.

## 데이터와 점수

재무와 배당은 6개 연도 후보에서 최근 유효한 5개년을 수집합니다. 조회 API, 점수, 리포트, 챗은 같은 수집 서비스와 캐시를 사용합니다. 밸류에이션도 같은 재무 스냅샷을 전달받으며 별도로 다른 기간의 실적을 조회하지 않습니다.

`provenance` / `data_quality`에 출처, 재무 기준연도, 수집시각, 누락 경고를 제공합니다. 수집시각은 주가 체결시각이 아닙니다. 밸류에이션 `history`는 **현재 시세를 각 연도 실적에 적용한 비교값**이며 과거 시세 이력이 아닙니다.

- 0과 결측값(null)을 구분합니다. 확인된 배당금 0은 유지하며 배당 조회 불가를 무배당으로 해석하지 않습니다.
- 평가에 필요한 입력이 없는 영역은 `score: null`, `grade: N/A`입니다. 누락 영역이 있으면 종합 점수도 null이며, 나머지 영역으로 임의 재가중하지 않습니다.
- `coverage`는 평가 가능한 영역의 가중치 비율입니다. 통계적 신뢰도나 개별 데이터 완전성을 뜻하지 않습니다.
- 연결·개별 재무제표 혼재 시 경고하고 성장성 점수를 제공하지 않습니다. 배당과 재무 최신 연도가 다르면 배당 점수는 평가 불가입니다.
- CAGR은 실제 경과 연도를 사용합니다. 음수로 전환된 이익의 CAGR을 계산하지 않으며, 누락 연도를 건너뛴 변화를 YoY로 부르지 않습니다.
- CapEx가 없으면 FCF를 계산하지 않습니다. 순이익의 임의 비율을 오너이익으로 대체하지 않습니다.
- FCF 기반 오너이익은 근사치입니다. 유지보수 CapEx를 분리한 정밀 평가가 아닙니다.
- 순부채 자료가 불완전하면 EV를 시가총액으로 대체하지 않습니다.

## 캐시와 비용

설정은 `simple_fast_api/config.py`에서 관리합니다.

| 데이터 | TTL |
|---|---:|
| 재무·배당·사업·내부자 현황 | 24시간 |
| 시세·정량 점수 | 15분 |
| 공시 목록·주요 사건 | 30분 |
| AI 리포트·내부자 해석 | 24시간 |

기존 스키마 캐시는 재사용하지 않습니다. 실제 입력과 분석 정책의 해시를 비교하므로 재무나 시세 입력이 달라지면 정량 점수/AI 해석을 다시 생성합니다. 조회시각만 바뀌면 같은 AI 결과를 재사용합니다. 실패한 AI 응답과 실패한 공시 목록 조회는 정상 결과로 캐싱하지 않습니다.

같은 프로세스 안에서 동일 회사에 대한 동시 수집·생성은 잠금으로 합칩니다. 여러 서버 프로세스 사이의 분산 잠금은 구현하지 않았습니다. 입력이 바뀌거나 TTL이 만료된 해석 요청에는 새 AI 호출이 발생합니다.

## 검증

```bash
simple_fast_api/.venv/bin/python -m unittest discover -s simple_fast_api/tests -v
cd frontend/next
npm run lint
npx tsc --noEmit
```

회귀 테스트는 외부 API를 대체하여 결측값·0·연도 누락·캐시 만료·동시 요청·실패 캐싱·단순 질문의 AI 무호출을 검증합니다. 실제 AI 생성 품질이나 DART 모든 업종/회계계정 매핑의 정확성을 검증하는 테스트는 아닙니다.

## 이번 범위 밖

공시 본문 비교 및 사용자별 투자 논리 추적, 웹/Telegram 계정 동기화, 사용자별 알림 재시도 큐는 별도 단계입니다. 현재 공시 알림은 접수 사실과 원문 링크만 제공하며 제목만으로 투자 영향을 생성하지 않습니다. 뉴스 전후 등락률은 사건의 인과효과가 아닙니다. 시세·공시의 완전한 실시간성을 보장하지 않습니다.

브라우저 회귀 검증은 로컬 개발 서버를 실행한 상태에서 다음과 같이 수행합니다. 외부 API 요청은 전부 모의 응답으로 대체합니다.

```bash
# frontend/next 에서 별도 터미널
npm run dev -- --hostname 127.0.0.1 --port 3104
TEST_BASE_URL=http://127.0.0.1:3104 node tests/ai-policy.cjs
```

정량 검색 시 AI 요청 0회, 즐겨찾기에서 리포트 화면 진입 시 0회, 명시적 생성마다 1회 요청, null 점수 렌더링과 브라우저 오류 없음을 확인합니다.
