# 최근 두 해 사업보고서 서술 변화

Telegram에서 `/changes 신성이엔지`, `/changes LG전자`, `/changes 011930`으로
최근 결산연도와 직전 결산연도의 사업보고서를 비교합니다. `/` 명령어 메뉴와
`/help`에도 등록합니다. API는 `GET /changes/{기업명 또는 종목코드}`입니다.

결과는 주요 제품·사업, 사업 방향·투자, 위험 요인의 **서술 변경 후보**를
주제별 최대 한 건씩 보여줍니다. 각 후보에는 전기·당기 원문 발췌, 보고서명,
공시일, DART 링크, 원문 파일과 색인 조각 범위를 제공합니다. 현재 달력의
작년·올해가 아니라 확보한 사업보고서의 결산연도로 표시합니다.

이미 사용하는 DART 전체 문서 색인을 재사용합니다. 각 보고서에서 주본문을
식별하고 같은 절 제목 아래의 본문을 대응시킵니다. 검색 조각의 겹치는 부분을
복원한 뒤 문장을 분리하고, 동일 문장·숫자/날짜/구두점만 바뀐 문장은 제외합니다.
유사 문장 중 글자쌍 겹침 비율이 설정 범위 안인 후보를 고릅니다. 제목의
단순 번호 변경은 허용하지만 사업부 명칭 변경을 임의로 같은 조직으로 연결하지 않습니다.

지원 범위는 대응 가능한 본문 서술입니다. 표·첨부 문서·완전히 새로 생기거나
사라진 절·대응 문장이 없는 추가/삭제는 비교하지 않습니다. 긴 절은 설정한
글자 수·문장 수 안에서 비교하고 지나치게 긴 문장은 제외합니다. 제한 여부와
대응/미대응 절 수를 응답에 표시합니다.
후보가 없다는 것은 실제 변화가 없다는 뜻이 아닙니다. 단순 문구 생략을 사업
철수·위험 감소로 단정하지 않으며, 수치 비교는 `/profit` 등 기존 기능을 사용합니다.

최신 정정본을 우선하고 직전 연도 자료가 없으면 404, 결산월이 다르거나 주본문을
확인할 수 없으면 422로 안내합니다. 다른 연도나 첨부 파일을 대신 사용하지 않습니다.
기업 식별 오류, 자료 부재, 외부 API 오류는 기존 봇 안내와 연계합니다.

변경 후보 선정과 핵심 표현 발췌는 Python으로 처리합니다. `달라진 원문 표현`은
실제 전기·당기 발췌의 연속 구절이며 생성형 AI의 자유 해설이 아닙니다. 원문에 없는
사업 진출·철수 등 주장을 추가하지 않습니다. 발췌 내용만으로 실제 사업 변화의
원인·성과를 확정할 수는 없습니다. 이 기능은 별도 AI API나 GPU 없이 동작합니다.

첫 조회는 두 보고서의 다운로드·색인으로 오래 걸릴 수 있습니다. 봇은 작업 중
안내 후 백그라운드에서 처리하고 한 사용자의 중복 실행을 제한합니다.
회사명 원문을 캐시 키로 사용하며 법인 고유번호·두 접수번호·비교/색인 버전이
같을 때 비교 결과를 재사용합니다. 보고서 수집 오류는 캐시하지 않습니다.
`GET /cache/status`의 `changes`에서 확인하고 기존 캐시 초기화 API로 삭제할 수 있습니다.
