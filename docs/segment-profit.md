# 사업부별 손익 상담

Telegram에서 `/chat LG전자`를 시작하고 다음과 같이 질문합니다.

- `사업영역 중 영업이익 비중도 알려줘`
- `2024년은?`
- `사업부별 매출 비중 알려줘`
- `사업부별 영업이익 비중의 의미를 분석해줘`처럼 지표를 지정하면 조회 수치와 계산 해설을 함께 받습니다.

수치는 모델이 만들거나 계산하지 않습니다. DART 최신 정정 사업보고서의 연결
영업부문 표에서 원문 금액을 추출하고, 표 내부 합계 및 동일 연도 연결 재무제표와
대조한 뒤 Python으로 비중을 계산합니다. 비중의 의미도 검증된 계산 해설로 제공합니다.
종합 상담 모델에는 `get_segment_financials` 도구로 검증된 수치를 제공할 수 있습니다.
실제 로컬 모델 검증에서 비중의 의미를 잘못 해석하는 사례가 있어, 이 숫자 조회 경로에서는 자유 생성 해석을 사용하지 않습니다.

`비중 = 사업부 금액 / 공시된 연결 합계 × 100`입니다. 적자 부문은 음수이며,
그 때문에 흑자 부문의 비중 합은 100%를 넘을 수 있습니다. 합계가 0 또는 음수이면
기여 비중을 표시하지 않습니다. 기타·조정 항목은 원문 그대로 포함합니다.
금액 표시는 조·억 단위로 반올림하지만 비중은 원문 금액으로 계산합니다.

답변에는 재무 기준연도, 결산월, 공시명·공시일·조회시각과 DART 원문 링크가 포함됩니다.
`작년`은 현재 달력의 전년, `전년`은 직전 상담 기준연도의 전년입니다.
후속 연도 질문은 직전 지표를 유지합니다.

현재는 **연간 연결 부문 표의 열에 사업부가 있고 행에 손익이 있는 형식**을 지원합니다.
가장 최근 보고서에 포함된 당기·전기·전전기 표 중 검증된 기간만 제공합니다.
분기·반기 요청, 지원하지 않는 표 형식, 기간·단위 미확인, 표 간 상충 또는 합계 불일치는
명확히 안내하며 숫자를 추정하지 않습니다. 회사마다 공시 형식이 달라 모든 기업이 지원되는 것은 아닙니다.

API: `GET /segments/{company_name}?year=2025`. 응답 금액 단위는 원이며
`cached`가 캐시 여부를 나타냅니다. 캐시 조회·초기화에도 `segments`가 포함됩니다.
